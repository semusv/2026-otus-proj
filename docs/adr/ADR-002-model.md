# ADR-002: Выбор модели

- Статус: принято
- Дата: 2026-08-25
- Связанные: ADR-001 (vLLM), ADR-006 (экстракция Concept этой моделью)

## Контекст

Модель должна: (1) хорошо работать с русским языком юридических текстов; (2) помещаться
в 16GB VRAM вместе с KV-cache при контексте до 8k токенов (GraphRAG кладёт в промпт чанки + путь графа);
(3) иметь готовый AWQ-чекпоинт для vLLM; (4) поддерживать JSON-mode для экстракции понятий.
Задание требует квантования AWQ.

Бюджет VRAM (16GB): веса Qwen3-8B-AWQ ≈ 6GB → остаётся ≈ 9–10GB на KV-cache и активации — комфортно.
Qwen3-14B-AWQ ≈ 9–10GB весов → KV-cache впритык, риск OOM на длинных контекстах.

## Решение

**Qwen3-8B-AWQ** как основная модель. Имя модели — только через конфиг (`APP_LLM_MODEL`), без хардкода.

## Trade-offs

| Критерий | Qwen3-8B-AWQ | Qwen3-14B-AWQ | T-lite/T-pro (T-Bank) | Saiga (community FT) |
|----------|--------------|----------------|----------------------|----------------------|
| Русский язык (формальный домен) | Хорошо | Лучше | Хорошо/лучше | Разговорный, слабее в юр. текстах |
| VRAM (веса, AWQ) | ~6GB | ~9–10GB | 8B/20+B варианты | зависит от базы |
| Запас под KV-cache @16GB | Большой | Впритык | средне | средне |
| Готовый AWQ для vLLM | Да | Да | Частично | Часто нет |
| JSON-mode / instruction following | Надёжный | Надёжный | Надёжный | Нестабильный |

## Последствия

- Положительные: гарантированно влезает с запасом; стабильная структурная генерация для экстракции
  `(:Concept)`; быстрая генерация на 8B — важно для SSE-стриминга.
- Отрицательные / риски:
  - качество ниже 14B — если LLM-as-a-Judge покажет слабую экстракцию Concept, план Б —
    переключение на Qwen3-14B-AWQ одной переменной конфига;
  - лицензия Apache-2.0 у Qwen3 — допустимо для учебного проекта.
