# ADR-006: GraphRAG-подход и онтология графа

- Статус: принято
- Дата: 2026-08-25
- Связанные: ADR-002 (модель экстракции), ADR-004 (Neo4j), этап 4 (ingestion)

## Контекст

Простой векторный поиск заданием не принимается: retrieval должен использовать граф знаний.
Корпус RusLawOD — полуструктурированные XML: значительная часть связей уже есть в метаданных
(издатель, классификатор, ссылки `<ref nd="ID">`), но неявные юридические понятия в тексте
метаданными не покрыты.

Проверено на corpus_test (100 файлов): `keywords` — CSV в одном атрибуте (~19% пустых),
классификатор — пары `код$Название$...` внутри обёртки `<reference>` (~18% пустых),
ссылки `<ref nd>` есть в ~20% файлов, статусы требуют нормализации, встречаются HTML-артефакты.

## Решение

**Гибридная экстракция** поверх фиксированной онтологии (4 типа узлов):

Узлы: `(:Act {id, title, doc_number, date, status})`, `(:Authority {name})`,
`(:Topic {name})`, `(:Concept {name})`.

Рёбра и способ получения:

| Ребро | Источник | Способ |
|-------|----------|--------|
| `(:Act)-[:ISSUED_BY]->(:Authority)` | атрибут `doc_author_normal_formIPS` | детерминированно |
| `(:Act)-[:REFERENCES]->(:Act)` | теги `<ref nd="ID">`; ребро только если целевой акт есть в корпусе | детерминированно |
| `(:Act)-[:HAS_TOPIC]->(:Topic)` | классификатор `$`-пар / keywords | детерминированно |
| `(:Act)-[:MENTIONS]->(:Concept)` | текст чанков, LLM-экстракция JSON-списком понятий | LLM (vLLM) |

Retrieval: vector search по чанкам → seed-акты → расширение графа 1–2 hop (`expand_graph`)
→ контекст включает связанные акты/понятия, которых нет в топ-k векторов.

## Trade-offs

| Критерий | Полностью LLM-экстракция | Полностью детерминированная | Гибрид (наш выбор) |
|----------|--------------------------|------------------------------|--------------------|
| Точность рёбер | Галлюцинации, шум | Высокая (данные первичны) | Высокая на детерминированной части |
| Неявные понятия текста | Да | Нет | Да (через Concept/MENTIONS) |
| Стоимость/скорость ingestion | Очень дорого (весь корпус через LLM) | Дёшево | Дорого только Concept-часть |
| Идемпотентность/тесты | Сложно | Просто (unit на парсере) | Детерминированная часть unit-тестируема |
| Демонстрация нейро-символичности | Частично | Нет | Да — ключевой аргумент защиты |

## Последствия

- Положительные: детерминированные рёбра бесплатны и воспроизводимы; MENTIONS показывает ценность
  LLM-слоя; расширение графа даёт ответы, недостижимые чистым vector RAG (связки актов).
- Отрицательные / риски:
  - две кодовые базы построения графа (parser + extraction prompt) — обе покрыты тестами;
  - качество Concept зависит от модели (ADR-002), промпт требует JSON-схемы и пост-валидации;
  - REFERENCES обрезается по наличию цели в корпусе — граф «замкнут» на загруженные акты.
